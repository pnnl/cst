# CONTRIBUTING to CoSim Toolbox

Thank you for being interested enough in CoSim Toolbox that you are thinking about contributing.

The following are the guidelines for contributing to CoSim Toolbox in this repository.

## How Can I Contribute?

### Reporting Bugs
When you are creating a bug report, please include as many details as possible. Frequently, helpful information includes operating system, version, compiler used, API, interface, and some details about the function or operation being performed.

> **Note:** If you find a **Closed** issue that seems like it is the same thing that you're experiencing, open a new issue and include a link to the original issue in the body of your new one.

### Fixing Bugs or Suggesting Enhancements
Please include as much detail as possible including the steps that you imagine you would take if the feature you're requesting existed, and the rational and reasoning of why this feature would be a good idea for CoSim Toolbox. Before submitting a bug fix or enhancement suggestion, please look through the existing [Github Issues](https://github.com/pnnl/cst/issues) to see if a similar request has already been submitted. If similar enough, adding a comment to the existing request is best. If too dis-similar, create a new request, link to the related issue you found, and explain the difference between your feature request and the related one.

### Submitting a Pull Request
Generally, create your new branch from "dev" as this is where the on-going work is being integrated in preparation for merging into "main" for release. As part of your pull request reference any relevant [Github Issues](https://github.com/pnnl/cst/issues) and otherwise describe the purpose of the pull request.
